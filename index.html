Задача 1 — float + адаптивность

Задача 1. Адаптивная верстка на float

Страница построена на float: left / right: .col-left { float:left; width:68% }, .col-right { float:right; width:30% }, родитель очищен через .clearfix::after { clear: both }. Есть <meta viewport>, картинки — max-width:100%, таблицы обернуты в .table-wrap с прокруткой.

Медиазапросы: при max-width: 900px колонки становятся float:none; width:100% (одна под другой), меню из горизонтального превращается в вертикальное. При max-width: 480px блоки трансформаций и галерея тоже перестраиваются в одну колонку.
